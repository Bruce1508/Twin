# Linguistic Twin

## Product context

Linguistic Twin is a personal French-learning workspace for Bruce, focused on steady progress toward TCF Canada B2 / NCLC 7. It remembers recurring mistakes, derives a learner profile from real practice, and turns weak points into targeted review.

## Current interface goal

- Make the next useful learning action obvious within a few seconds.
- Keep French as the main working language, with concise Vietnamese guidance where it reduces friction.
- Present the product as a correction ledger: direct, structured, warm, and personal.
- Preserve the existing learning flows and API behavior while unifying the interface.

## Design direction

The approved direction is **Correction Ledger (A)**. It adapts RawBlock's heavy rules, square controls, type-led hierarchy, and lack of shadows to a warmer study-book surface. Ink is navy rather than pure black; red marks errors, green marks progress, and blue is reserved for links and current actions.

## Inferred context

The primary user, daily-use pattern, language balance, and whole-app redesign scope were inferred from the repository and the user's request. These can be revised when product requirements change.
